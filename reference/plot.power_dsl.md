# Summarizing estimates from DSL estimators

Summarizing estimates from DSL estimators

## Usage

``` r
# S3 method for class 'power_dsl'
plot(x, coef_name = NULL, ...)
```

## Arguments

- x:

  An output from function `power_dsl`.

- coef_name:

  A name of a coefficient users want to visualize. When `NULL`, the
  function visualizes every coefficient.

- ...:

  Other arguments.
