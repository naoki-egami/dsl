# Summary function for `dsl`

Summary function for `dsl`

## Usage

``` r
# S3 method for class 'dsl'
summary(object, ci = 0.95, digits = 4, ...)
```

## Arguments

- object:

  An output from function `dsl`.

- ci:

  A coverage rate of confidence intervals. Default is `0.95`, which
  reports 95% confidence intervals.

- digits:

  The number of digits reported.

- ...:

  Other arguments.
